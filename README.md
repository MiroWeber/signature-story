# signature-story.tv

Statische Website für Signature Story (Miro Weber), gehostet auf bunny.net.

- `site/` – alles, was live geht (HTML, CSS, Schriften, Bilder, Video)
- Deploy: bei jedem Push auf `main` per GitHub Actions in die Bunny Storage Zone
- Schriften: Cormorant Garamond und Jost, lokal eingebunden (SIL Open Font License)
